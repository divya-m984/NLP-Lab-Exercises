  5. Lemmatize using WordNet lemmatizer
  6. Remove tokens shorter than 2 characters

------------------------------------------------------------------------
CLASSIFIER DESCRIPTIONS
------------------------------------------------------------------------

A. Rule-Based Legal Classifier
   Deterministic weighted keyword and phrase matching.
   Multi-word phrases receive higher weights (4.0-5.0).
   Single keywords receive weights of 1.5-3.0.
   Tie-breaking: first category in predefined order.
   Fallback: 'contract' when no clue matches.
   Training time is 0 (predefined rules, no learning).

B. Multinomial Naive Bayes
   TF-IDF features with unigrams and bigrams, sublinear TF.
   MultinomialNB with default parameters.

C. Linear Support Vector Machine
   TF-IDF features with unigrams and bigrams, sublinear TF.
   LinearSVC with balanced class weights, random_state=42.

D. Maximum Entropy Classifier (Logistic Regression)
   TF-IDF features with unigrams and bigrams, sublinear TF.
   LogisticRegression (multinomial) with max_iter=2000,
   balanced class weights, random_state=42.
   Multinomial Logistic Regression is mathematically equivalent
   to the Maximum Entropy classifier.
