==============================================================================
  Model Descriptions
==============================================================================

  A. Proper-Noun POS Baseline
     Tokenize and POS-tag each sentence. Classify consecutive NNP/NNPS
     tokens as PERSON; all others as O. A deliberately simple baseline.

  B. Rule-Based Legal NER
     Uses deterministic patterns and embedded gazetteers to detect PERSON,
     ORGANIZATION, LOCATION, and LEGAL_REFERENCE entities from titles,
     organization suffixes, location vocabulary, and legal patterns.

  C. NLTK ne_chunk
     Applies POS tagging followed by nltk.ne_chunk. Maps chunk labels to
     the target entity types and adds rule-based LEGAL_REFERENCE detection.

  D. Supervised Logistic Regression Token Classifier
     Trains a token-level multiclass LogisticRegression model on contextual
     features (token shape, POS, context window, gazetteers). Uses
     class_weight='balanced', max_iter=1000, random_state=42.
